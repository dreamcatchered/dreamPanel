# Демо-панель управления сервером

Полная демонстрационная версия панели управления сервером без Flask и зависимостей.

## Описание

Это демо-версия панели управления, которая полностью повторяет дизайн и функциональность оригинальной панели, но работает на чистом HTML/JavaScript без серверной части.

## Возможности

- ✅ Полный дизайн оригинальной панели
- ✅ Все разделы работают (Dashboard, Сервисы, Сайты, Файлы, Nginx, SSL, Бэкапы, Безопасность, Проекты)
- ✅ Можно открывать и просматривать файлы
- ✅ Редактирование файлов в CodeMirror
- ✅ Демо-данные для всех разделов
- ✅ Сервис dreamShare добавлен в демо-данные
- ✅ Без реальной информации о сервере

## Использование

1. Откройте `index.html` в браузере
2. Войдите с данными:
   - Логин: `admin`
   - Пароль: `demo`
3. Исследуйте панель - все функции работают в демо-режиме

## Структура

```
admin_panel_demo/
├── index.html              # Страница входа
├── dashboard.html          # Основная панель
├── static/
│   └── js/
│       ├── demo-data.js    # Демо-данные
│       └── demo-functions.js # Функции панели
└── README.md
```

## Демо-данные

В панели представлены следующие демо-данные:

### Сервисы
- dreamGPT AI
- **dreamShare** (новый сервис)
- dreamPartners CPA
- SwagPlayer
- Nginx
- PostgreSQL
- Redis

### Сайты
- dreampartners.ru
- ai.dreampartners.online
- **share.dreampartners.online** (новый сайт)
- swag.dreampartners.online
- auth.dreampartners.online

### Файлы
- Демо-файлы в `/var/www/dreamshare/`
- Конфиги Nginx
- Примеры кода

## Примечания

- Все действия показывают уведомления "демо"
- Файлы можно открывать и просматривать
- Редактирование файлов работает, но изменения не сохраняются на сервере
- Все данные статичны и не изменяются

## Для клиентов

Эта демо-панель показывает возможности системы управления сервером без доступа к реальному серверу. Все функции работают так же, как в реальной панели, но с демонстрационными данными.
